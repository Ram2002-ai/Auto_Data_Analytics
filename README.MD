#  AI Data Analyst App

A complete end-to-end **AI-powered Data Analysis Platform** that takes raw data and transforms it into **insights, visualizations, and predictions** — all in one place.

---

## 🚀 Complete Workflow

```
RAW DATA → CLEANING → TRANSFORMATION → EDA → VISUALIZATION → ML → INSIGHTS → CHATBOT
```

---

# 📂 1. Upload Dataset

* Upload **CSV / Excel files**
* Preview dataset
* Auto-detect:

  * Column types
  * Row & column count

---

# 🧹 2. Data Preprocessing (5 Tabs)

## 🔹 Tab 1: Overview

* Dataset shape (rows/columns)
* Missing data %
* Data quality table
* Missing values heatmap

## 🔹 Tab 2: Clean Data

* Remove duplicates
* Handle missing values:

  * Mean / Median / Mode
  * KNN Imputer
  * Drop rows
* Outlier detection (IQR method)

## 🔹 Tab 3: Transform

* Create new features (log, square, etc.)
* Rename columns
* Drop columns
* Change data types

## 🔹 Tab 4: Scale & Encode

* Feature Scaling:

  * StandardScaler
  * MinMaxScaler
* Encoding:

  * Label Encoding
  * One-Hot Encoding

## 🔹 Tab 5: Feature Engineering

* Feature interactions
* Feature binning
* Download processed dataset

# 🤖 5. Machine Learning (5 Tabs)
